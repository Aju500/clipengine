Privacy Policy

ClipEngine. Last updated October 25, 2026.

What ClipEngine is

ClipEngine is a personal automation tool operated by a single developer to post short highlight videos to the developer's own social media accounts (YouTube and, where enabled, TikTok). It is not offered to the public. People the developer authorizes to run it may only connect accounts the developer owns or manages.

Google user data we access

ClipEngine requests two Google OAuth scopes for the developer's own Google account only:

  • youtube.upload: to upload finished videos to the developer's channel.
  • youtube.readonly: to read public video listings from whitelisted creators' channels in order to find clip sources.

TikTok user data we access

If TikTok posting is enabled, ClipEngine requests these TikTok scopes for the developer's own TikTok account only:

  • user.info.basic: to show which account is connected (display name and avatar) before posting.
  • video.publish and/or video.upload: to post finished videos, or send them to the account's drafts, for the developer to review.

ClipEngine does not read followers, messages, comments, analytics, or any other TikTok data.

How data is used and stored

OAuth tokens are stored only on the developer's own computer and are used only to perform the actions above. ClipEngine does not collect, sell, share, or transfer Google or TikTok user data to any third party, and does not use it for advertising. No data from any other user is accessed.

Content processing

To find and check clips, ClipEngine reads public information about whitelisted creators' content (video titles, public comments, Twitch clip listings) and sends short segments of that public content to Google's Gemini API for analysis, under Google's API terms. It does not send any account tokens or personal data of viewers. Clips are credited to their creators, and a creator can ask for removal using the contact link below.

Revoking access and deleting data

Google access can be revoked at any time at myaccount.google.com/permissions, and TikTok access from the TikTok app under Settings and privacy → Security → Apps and services permissions. Revoking access, or deleting ClipEngine's token file from the developer's computer, ends all access; ClipEngine keeps no other copy of account data. ClipEngine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads are also subject to the YouTube Terms of Service and the Google Privacy Policy. TikTok posting is subject to the TikTok Terms of Service and TikTok Privacy Policy. See also our Terms of Service.
